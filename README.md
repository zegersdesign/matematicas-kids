# Matemáticas Kids 🧮

Web app lúdica para enseñar matemáticas a niños de forma visual y divertida.

## Idea
Ejercicios interactivos, retroalimentación inmediata y un diseño amigable para que los más chicos aprendan sumas, restas y otras operaciones básicas jugando.

## Estado
Prototipo educativo — parte de un conjunto de proyectos EdTech de [AprendamosIA](https://www.aprendamosia.cl/).
